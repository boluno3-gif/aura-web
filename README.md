# AURA Design

Web de lámparas de mesa impresas en 3D en Málaga.

Web estática (HTML, CSS y JavaScript), sin instalación: abre `index.html` en el navegador.

- `index.html`: la página
- `css/styles.css`: estilos (colores y tipografías al principio del archivo)
- `js/main.js`: lámparas, precios, oferta y preguntas frecuentes (editables al principio del archivo)
- `assets/`: fotos, vídeo e icono
